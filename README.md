# toss-portfolio

토스 비주얼 디자이너 포트폴리오 프로젝트입니다.

## Nunbit

NUNBIT은 연령성 청각 저하를 가진 시장 상인을 위한 투명 아크릴 대화 보조 장치입니다.
손님의 목소리를 실시간으로 텍스트로 변환하여 투명 패널 위에 표시함으로써,
상인이 손님의 얼굴에서 시선을 떼지 않고 대화를 이어갈 수 있도록 합니다.

### 파일 구조
- `nunbit_v2.html` — 인터랙션 프로토타입 (단일 HTML 파일)
- `intro.mp4` — 인트로 영상
- `customer.mp4` — 고객 인터랙션 영상

### 실행 방법
```bash
cd Nunbit
python3 -m http.server 8765
# 브라우저에서 http://localhost:8765/nunbit_v2.html 접속
```
